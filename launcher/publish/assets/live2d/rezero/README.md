The models are game-extracted character assets. The upstream repository provides no explicit redistribution license. Original character, artwork and game asset rights remain with their respective owners; availability on GitHub does not grant an open-source license. See SOURCE.json for exact source directories and local modifications.

The model manifests organize existing motions into Idle, TapBody, Expressions and Actions. Texture, model, physics and motion data are unchanged. The website maps the models’ PARAM_* focus parameters through per-model configuration.
