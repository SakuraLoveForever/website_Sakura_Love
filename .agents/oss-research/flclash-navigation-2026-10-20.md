- 官方仓库：https://github.com/chen08209/FlClash ，本次 API 查询 56,886 Star。
- 最新发布 v0.9.1，2026-10-17 发布；核对该标签的 [sidebar.dart](https://github.com/chen08209/FlClash/blob/v0.9.1/lib/ui/sidebar.dart)。
- 原版使用 Flutter；选中背景为低透明度中性色。左侧指示条 3×16，320ms，朝目标的边先移动，另一边延迟跟上。侧栏展开约 250ms。

- 集成成本低：一个共享装饰指示条，沿用当前侧栏状态更新入口；手机换行导航改为下划线方向，尺寸变化即时重新测量。首次显示与减少动态效果模式不做拉伸。
- CSS 过渡由浏览器从当前位置接续，连续点击无需动画队列；与 Flutter 渲染时序及曲线采样存在细微差异，不宣称逐像素复刻。
- 验证：浏览器逐帧采样拉伸与收拢；连续反向点击、键盘 Enter、收起侧栏、354/390px 手机换行、滚动选中状态与减少动态效果模式。

## 内容导航与布局衔接

用户已确认采用本轮方案。另查该版本 [page_transition.dart](https://github.com/chen08209/FlClash/blob/v0.9.1/lib/ui/page_transition.dart) 与 [layout.dart](https://github.com/chen08209/FlClash/blob/v0.9.1/lib/common/layout.dart)。原版推入页面使用 450ms 位移与分段淡入；这不是侧栏切换全部场景的时长。布局按窗口档位调整，笔记本档位优先紧凑侧栏以保留内容宽度。

本站保留长页面浏览：所有站内锚点统一经过 按距离 360–1100ms 的平滑滚动；按用户撕裂反馈取消整块内容入场，测量前固定所有内容的显露状态，终点只测量一次，滚动帧中不再读取变化的布局；去掉旧光圈与页脚二次滚动。新点击取消旧滚动；滚轮、触摸、翻页键或窗口尺寸变化可中断；按用户后续明确要求，侧栏点击即使在系统减少动态效果模式下也执行快速滚动，但不做额外内容入场；其他锚点仍遵循减少动态效果直接定位。沿用链接 hash 和浏览器后退，修饰键点击仍由浏览器处理。

侧栏和正文左侧间距统一为 250ms，标签单行裁切。834–1100px 默认紧凑侧栏；明确保存的手动展开/收起偏好优先。手机继续使用现有响应式导航。仅独立实现交互，不复用 Dart 源码或添加依赖。
